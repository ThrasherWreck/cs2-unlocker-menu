## 🧩 About

**Counter-Strike 2 Companion** is a curated list of Counter-Strike 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, position switcher
- **Quality-of-Life Helpers** — loadout catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Position Switcher — practice from any checkpoint
- Show Hitboxes — visualize hitboxes
- Replay Notes — record and review match runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Skin Catalog — browse skins, colors, patterns, stickers
- Custom Loadout Notes — organize player cosmetics
- Crosshair Overlay — improved crosshair visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Movement Control — manually switch movement mid-match
- Jump Throw Notes — chain complex maneuvers in practice
